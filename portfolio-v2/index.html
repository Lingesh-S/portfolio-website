01 About me

Building intelligent systems that make a difference

I'm a Data Scientist working at a product-based company, building and deploying production-grade ML and GenAI systems used in real enterprise workflows. My work focuses on turning complex AI models into reliable, scalable features that solve concrete business problems.

At DataTracks, I work on XBRL auto-tagging systems using LSTM and NER models, and design taxonomy-specific ML pipelines across multiple regulatory domains. I've trained and deployed models for newly introduced taxonomies and maintain independent pipelines to support region-specific requirements.

I've also built RAG-based systems for real-time applications, including LLM-powered features inside a Word-like editor. These systems are designed for low-latency inference and production monitoring, using tools like FastAPI, Haystack, RabbitMQ, Grafana, and Prometheus.

My research work has been published at international conferences, and I actively experiment with modern GenAI tooling such as LangChain and retrieval systems to improve how large language models are used in enterprise products.

AWS Bedrock RAG-Based Knowledge Assistant

A Retrieval-Augmented Generation system built on AWS Bedrock (Titan LLM) and LangChain for context-aware question answering over custom knowledge sources.

  • Ingests, chunks and embeds documents with Amazon Titan Embeddings; vectors live in ChromaDB for semantic search.
  • Retrieval + generation keeps answers grounded, significantly reducing hallucinations.
  • Real-time Streamlit interface, now being extended with AWS S3 storage and EC2 deployment.

02 GenAI · RAG

Codebase RAG Assistant

Ask questions about a codebase in plain English. A RAG system that pairs Mistral-7B (built on PyTorch) with semantic search over a vector store for code understanding and explanation.

  • Loads and chunks .py, .md and .json files, embeds them with SentenceTransformers and stores them in Chroma/FAISS for high-precision code retrieval.
  • LangChain orchestrates retrieval and Mistral-7B generation for real-time explanations.
  • Modular Streamlit assistant for developer support.

05 NLP · Research Published at ICCCAI-2024

LDA-Powered Resume Screening Dashboard

Presented at ICCCAI-2024 (Taylor's University, Malaysia). An interactive Streamlit dashboard that uses LDA to surface dominant topics and keywords from resumes and match them to roles.

  • Custom NLP job-matching algorithm with token indexing, reaching >80% accuracy in simulated resume screenings.
  • OpenAI API auto-generates personalized interview questions for recruiters.
